# Obsidian Sync (v0.6.0) — Notion 스타일 마크다운 스튜디오 & 실시간 동기화

**Obsidian 볼트 호환 지식 베이스 + 네이버(NHN) TOAST UI Editor 확장 스튜디오 + A4 인쇄/PDF + AES-256-GCM 암호화 + 6종 클라우드/NAS 실시간 동기화**를 하나의 가벼운 Rust 앱(`ObsidianSync.exe`)으로 통합한 Windows · Android 프로젝트입니다.

노트를 편집하고 저장하면 몇 초 안에 내 저장소(Synology NAS, OneDrive, Google Drive, 네이버 클라우드 등)로 올라가고, 다른 기기에서 바꾼 내용은 자동으로 내려받습니다.
Obsidian 공식 제품이 아닌 개인 오픈소스 프로젝트입니다.

## 주요 기능 (v0.6.0)

### 1. Notion 감성 워크스페이스 + 2배 이상 확장된 TOAST UI Editor (초슬림 도구함)
- **아이콘 50% 축소 컴팩트 도구함**: 상단 툴바 아이콘을 기존 대비 약 50% 크기로 정밀 축소·고밀도 배치하여, 작은 노트 화면에서도 2줄 이내로 **50여 종의 편집 도구(80+ 액션)** 를 한눈에 사용할 수 있습니다.
- **위지윅(WYSIWYG) ↔ 마크다운 듀얼 모드**:
  - **히스토리 & 찾기/바꾸기**: 실행 취소(`Ctrl+Z`) / 다시 실행(`Ctrl+Y`), 본문 내 찾기·바꾸기 바(`Ctrl+F` / `Ctrl+H`)
  - **제목 · 글자 · 서식**: `H1~H6` 빠른 제목, 글자 크기(`11~32px`), 굵게, 기울임, **밑줄**, 취소선, 위첨자(`x²`), 아래첨자(`H₂O`), 키보드 키(`Ctrl`), 서식 지우기
  - **색상 & 정렬**: 16색 글자 색상 팔레트, 6색 배경 형광펜 + `==마크다운 형광펜==`, 문단 정렬(왼쪽/가운데/오른쪽/양쪽)
  - **블록 & 레이아웃**: 12종 Notion 스타일 콜아웃(`Note/Tip/Info/Warning/Danger` 등), 접기/펼치기 토글(`<details>`), **2단/3단 다단 컬럼**, 명시적 페이지 나누기, 자동 목차(`TOC`), 인용구, 목록, 체크리스트, 들여쓰기/내어쓰기
  - **표 · 미디어 · 전문 요소**: 표 생성·행/열 편집·셀 병합, 링크, `[[위키링크]]`, 각주(`[^1]`), PC 이미지 업로드 및 **일반 파일 첨부(`📎` — PDF/Office/ZIP 등 볼트 `attachments/` 저장)**, 인라인/블록 코드 하이라이트, LaTeX 수식 및 28종 수학·그리스 기호, Mermaid 다이어그램
  - **생산성 유틸리티**: 날짜/시간/D-Day 삽입, 상태 배지(`진행중/완료/보류/긴급`), 진행률 바, 한글 사무용 기호(`※ ▶ ● ★ ☐ ☑`), 대소문자·공백 변환, 업무용 템플릿(회의록/업무계획서/보고서/트러블슈팅), 마크다운 복사, 확대/축소, 스크롤 동기화
- **Notion 페이지 헤더 & 다중 탭 · 분할 보기**: 아이콘(이모지), 커버 배너, 다중 탭, 우측 분할 보기, 다크/라이트 테마, 명령어 팔레트(`Ctrl+K`).

### 2. 태그 기본 숨김 & 필요 시 토글 보기
- 평소에는 깔끔한 문서 집중 화면을 위해 사이드바 태그 클라우드와 노트 상단 `tags` 속성 행이 **기본으로 숨겨져** 있습니다.
- 필요할 때 상단 툴바의 **`🏷️`** 버튼, 노트 속성 영역의 **`🏷️ 태그 보기`**, 사이드바 태그 헤더 **`보기/숨기기`**, 또는 `Ctrl+K` 명령 팔레트로 즉시 켜고 끌 수 있습니다.

### 3. ISO A4 용지 작성 캔버스 & 1:1 인쇄 / PDF 내보내기 (사용자 지정 여백)
- **A4 용지 기준 작성 화면**: ISO A4 용지(`210×297mm` 세로 / `297×210mm` 가로) 위에 작성하며, 모니터 해상도에 맞춰 자동 배율 축소(`auto_fit_a4`) 및 선택적 `297mm` 페이지 구분선 가이드를 제공합니다. 필요시 **전체 화면 폭 모드**와 자유롭게 전환할 수 있습니다.
- **사용자 지정 여백 (화면 · 인쇄 · PDF 1:1 일치)**:
  - **기본 여백**: **상단 `2.0 cm` · 하단 `1.0 cm` · 좌측 `3.0 cm` · 우측 `3.0 cm`** (`15.0 cm` 본문 폭으로 화면·인쇄·PDF가 오차 없이 동일하게 배치됩니다.)
  - 용지 설정 모달(`📐`)에서 상/하/좌/우 여백을 `0.0 ~ 6.0 cm` 범위로 미세 조정하거나 프리셋을 선택할 수 있습니다.
- **네이티브 인쇄 & PDF 출력**: **`Ctrl+P` 인쇄** 및 WebView2 네이티브 **PDF로 내보내기(`📄PDF`)** 를 지원합니다.

### 4. 볼트별 일일 문서(`Daily`) 저장 폴더 설정
- 일일 문서(`Ctrl+D`) 옆 **`⚙️` 설정 버튼**에서 오늘의 일일 노트가 생성될 폴더를 **볼트별로 개별 지정**할 수 있습니다.
- 볼트 루트, 기존 하위 폴더 선택은 물론, **`일일업무`** 등 새 폴더 이름을 입력하면 즉시 생성·적용됩니다.

### 5. 개별 문서 및 전체 볼트 암호화 (`AES-256-GCM`)
- 민감한 노트만 개별 암호화하거나, **볼트 전체 일괄 암호화** 및 **새 노트/일일 노트 생성 시 자동 암호화**를 지원합니다.
- **강력한 표준 암호화**: `PBKDF2-HMAC-SHA256` (210,000회 키 유도) + `AES-256-GCM` 인증 암호화 + 메모리 키 제로화(`zeroize`)를 적용했습니다.
- **6종 클라우드/NAS 동기화 100% 호환**: 암호화된 노트 역시 표준 `.md` 파일(Frontmatter 메타데이터 + `OBSIDIAN-SYNC AES256-GCM` 아머 블록)로 저장되므로 Synology NAS, OneDrive, Google Drive, S3 등 모든 동기화 백엔드를 그대로 활용할 수 있습니다.
- 암호화·해제는 **RAM 세션**에만 키가 유지되며 앱 종료 시 자동으로 다시 잠깁니다. 언제든 영구 복호화(평문 `.md` 되돌리기)도 가능합니다.

### 6. Obsidian 볼트 호환 & 검증된 6종 저장소 실시간 동기화 (`obsidian-sync-core`)
**프로필**마다 `내 기기 폴더 ↔ 저장소 폴더`를 1:1로 연결하며, Obsidian 볼트뿐 아니라 사진·일반 문서 폴더 프로필도 여러 개 함께 운영할 수 있습니다.

| 저장소 | 연결 방법 | 필요한 것 |
| --- | --- | --- |
| **Synology NAS** | DSM File Station API (계정 로그인, 2단계 OTP 인증, 원격 폴더 탐색기 지원) | NAS 주소, 아이디, 비밀번호 |
| **폴더 / 공유 드라이브** | 폴더 지정 | NAS 공유폴더(`\\NAS\...`), 매핑 드라이브, 외장 디스크 |
| **OneDrive** | 브라우저 디바이스 코드 로그인 | Microsoft 계정 + 앱 Client ID (최초 1회 등록) |
| **Google Drive** | 브라우저 디바이스 코드 로그인 | Google 계정 + OAuth Client ID/Secret (최초 1회 등록) |
| **네이버 클라우드** Object Storage | S3 호환 | 버킷, Access Key, Secret Key |
| **Google Cloud Storage** | S3 호환 (HMAC) | 버킷, HMAC 키 |

저장소별 자세한 설정은 [설정 안내](docs/SETUP.md)를 보세요.

## 동기화 설정 방법 (3분)

1. 좌측 사이드바 하단 또는 메뉴의 **🔄 동기화 센터 → 프로필 및 저장소 설정**을 엽니다. `＋ Obsidian 볼트` 또는 `＋ 일반 폴더 (사진 등)`로 프로필을 추가합니다.
2. **① 이름과 종류** → 프로필 이름과 종류를 정합니다.
3. **② 내 폴더** → 동기화할 로컬 폴더를 고릅니다.
4. **③ 저장소** → 카드 중 하나를 누르고 칸을 채웁니다. Synology는 **NAS에서 고르기…**로 원격 공유 폴더 목록에서 바로 고를 수 있습니다.
5. **④ 연결 확인** → `연결 테스트`. 2단계 인증을 쓰는 계정이면 OTP 코드를 한 번 입력합니다 (이후 이 PC를 기억).
6. **⑤ 동기화 방식** → 세 가지 방향 중 하나를 고릅니다.
   - *양방향*: 어느 쪽에서 바꿔도 맞춥니다. 충돌 시 **데이터 기준**(둘 다 보존 / 이 PC 기준 / 저장소 기준)을 고를 수 있습니다.
   - *올리기만 (백업)*: 사진 백업 등에 추천합니다 (내 기기에서 지워도 저장소에는 남음).
   - *내려받기만*: 저장소의 폴더를 이 기기로 받아 두기만 합니다.
7. **저장하고 동기화 시작** → 완료!

- **Windows**: 창을 닫아도 시스템 트레이(시계 옆)에서 계속 동기화합니다. `고급 설정`에서 *Windows 시작 시 자동 실행*을 켤 수 있습니다.
- **Android**: 알림 영역에 "Obsidian 실시간 동기화"가 떠 있는 동안 동기화하며, 재부팅 시 자동 시작됩니다.

## 안전장치

- **양쪽에서 같은 노트를 고친 경우**: 기본적으로 둘 다 남깁니다 (`노트 (충돌 기기이름 날짜).md`).
- **지워진 파일**: 볼트의 `.trash` 폴더로 안전하게 옮겨지며, 앱 내 휴지통에서 복원할 수 있습니다.
- **대용량 파일**: 사진·동영상은 메모리에 올리지 않고 스트리밍으로 주고받습니다.
- **대량 삭제 보호**: 원격이나 볼트가 갑자기 비었거나 한 번에 많은 파일이 지워질 상황이면 동기화를 보류하고 사용자 승인을 기다립니다.
- `.obsidian/workspace*.json`, `.trash`, `.git`, 임시 파일은 동기화하지 않으며 제외 패턴을 직접 추가할 수 있습니다.

## 개발 구조 및 빌드

```
crates/core          공통 동기화 엔진 (Rust) - 6종 저장소 연결, 3-way 비교, 실시간 파일 감시
crates/desktop       Windows 통합 앱 (Rust + Tao/Wry WebView2) - 볼트 엔진, AES-256 암호화, PDF 출력, 트레이
crates/desktop/web   프론트엔드 소스 (TypeScript, Vite, Notion UI, @toast-ui/editor, A4/인쇄 캔버스)
crates/android       Android 연결부 (Rust JNI)
android/             Android 앱 (Java) - 화면, 상주 서비스, 부팅 시 시작
```

```sh
# 프론트엔드 번들 빌드 (수정 시)
cd crates/desktop/web && npm install && npm run build

# 코어 / 데스크톱 테스트 및 Windows 단일 실행 파일 빌드
cargo test -p obsidian-sync-core -p obsidian-sync-android -p obsidian-sync-desktop
cargo build --release -p obsidian-sync-desktop
```

설계 설명은 [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)에 있습니다.
